# 双 Pluto 官方波源 Web 实时诊断

该工具为独立测试程序，浏览器可独立启动 A 或 B 任意一路 Pluto，也可按需同时
启动两路，并实时显示正式接收链路的：

- 正式 Pluto 采样数据的频谱与瀑布图；
- OTA/协议帧解析频率、当前成功率和累计成功率；
- RMS dBFS、Pluto 实际 RX 增益、削顶、SNR 估计、频偏和占用带宽；
- `0x0A01~0x0A06` 完整协议解析内容。

信息波页面顶部固定显示五张独立帧率卡，即使当前帧率为零也不会隐藏。业务字段区会持续缓存并展示最近一次有效解析结果和每个命令独立的 3 秒滚动帧率：`0x0A01` 六类机器人坐标、
`0x0A02` 血量、`0x0A03` 允许发弹量、`0x0A04` 金币与增益点状态、`0x0A05`
五类机器人增益/主状态和哨兵姿态。干扰波 `0x0A06` 的六字节密钥会使用大号字体
单独显示。信息波帧率直接复用正式 `filter_info_wave_updates`：重叠窗口中的相同 `seq+payload` 会去重，乱序返回的旧窗口不会
重复计数。选择干扰波时不显示“最近协议帧”列表，只显示当前密钥、密钥帧率和累计数量。
正式 OTA 解析会从每个精确匹配的 access-code bit 位置独立严格组包，
因此符号同步在空闲段重新锁定导致 bit-to-byte 对齐变化时，不会再丢掉
其他对齐位置上的合法包。access code、OTA 头和协议 CRC 均未放宽。

页面不展示原始 IQ 或额外鉴频预览，也不会为了画图增加另一套解调；频谱使用正式
Pluto 连续采集到的原始样本，业务结果只来自正式比赛解码 worker 的 CRC 有效输出。
浏览器以 `150 ms` 周期读取最新快照，图表最高约 `6.7 FPS`。
干扰波频谱从同一个正式采集循环中只读抽取，并与完整解析结果分开发布；
密钥及其帧率仍只在正式 `1.5 s` 窗口完成后更新。这些显示改动不修改
信息波正式连续窗口、干扰波采集窗口或任何协议解析算法。
信息波图表同样只从当前 `25 ms` Pluto 帧生成轻量快照，不再为了
显示而每帧搬移大块 IQ 环形数组，避免 Web 诊断自身造成采样缺口。

## 启动

```bash
cd RM2026_Waves_Analyze
./run_pluto_wave_web_diagnostic.sh
```

浏览器访问：

```text
http://127.0.0.1:8766
```

网页默认填写：

- 通道 A：`ip:192.168.2.1`，红方信息波；
- 通道 B：`ip:192.168.3.1`，红方一级干扰波；
- 通道 A、通道 B 均有独立的启动和停止按钮，不要求双路同时启动。

网页只允许修改 Pluto IP 和接收波源。其他参数全部固定为正式比赛设置，包括
`Fs=1 MHz`、`SPS=47`、`BT=0.35`、信息波 1 MHz/干扰波 2 MHz Pluto 采样、Fast Attack AGC、
波源严格硬件带宽、正式通道滤波、正交鉴频和过零符号同步。干扰波使用正式
`1.5 s` 采集窗口；信息波使用正式连续链路的 `250 ms` 窗口、`100 ms` 步长
和两个解码 worker。

点击某路启动时，服务会先执行 `iio_info -u ip:x.x.x.x` 并确认存在
`ad9361-phy`。设备不存在、连接超时、IIO 初始化失败或已被另一路占用时，错误会
直接显示在网页，该路 MATLAB worker 不会启动。

## 与正式比赛隔离

- MATLAB worker 直接调用正式 `FSK_RRC_Recv` 和正式波源配置；
- 不监听 `5006/5008`，不向 `5007` 发包，不发送裁判串口消息；
- 检测到 `FSK_RRC_AutoMatchUdp` 正在运行时，网页启动操作会失败；
- Web 服务默认只绑定 `127.0.0.1`，不会暴露到局域网；
- 关闭 Web 服务或点击网页停止按钮都会释放两块 Pluto。

三级干扰波选项用于自制发射源、接收链路和物理层协议测试，不表示正式自动流程会解析三级干扰波。

`dBFS` 是归一化 ADC 幅度，不是校准后的绝对 `dBm`。使用 AGC 时，应结合网页显示的
实际 RX 增益判断信号强弱：相同 dBFS 下所需增益越低，通常表示输入信号越强。
