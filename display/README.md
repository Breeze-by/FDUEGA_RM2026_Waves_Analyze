# 展示素材

本目录保存项目在 RoboMaster 比赛中的实际效果图片和解析结果利用视频，不是程序运行依赖。

| 文件 | 内容 |
|---|---|
| `雷达局均易伤全国第一.jpg` | 全国总决赛官方雷达数据展示 |
| `哨兵机器人命中率全国第一.jpg` | 全国总决赛官方哨兵数据展示 |
| `局均易伤时间和解析次数全国第一.png` | 赛事统计结果 |
| `场均14秒解出三级干扰波.png` | 三级干扰波解析能力 |
| `web端调试页面.jpg` | 双 Pluto Web 实时调试页面 |
| `敌方无人机发弹量、剩余经济实时显示.mp4` | `0x02AA` 工程操作手 UI |
| `敌方血量、增益、发弹量实时显示.mp4` | `0x02AB` 动态目标 UI |
| `哨兵不打无敌目标.mp4` | `0x0233` 哨兵目标筛选 |
| `哨兵过洞路径判断.mp4` | `0x0A01/0x0305` 坐标再利用 |

完整说明见[比赛实绩与应用案例](../docs/results_showcase.md)。
